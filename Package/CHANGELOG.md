# Changelog

## 1.0.0
- Initial release
- Progressive perks on every Woodcutting skill point: item yield, falling-tree damage, forest speed and felled-log HP
- Milestones: HP on aim (10), stumps 1 HP (20), felling stamina (30), axe combo (40), felling blow (50), axe conservation (60), XP boost (80)
- Configurable stump and log HP in section "2 - Stumps and Logs", replacing StumpsAreOneHp
- Classic behavior presets for existing StumpsAreOneHp and AxeComboWhenChoppingTree users
- Server-locked configuration synced from the server with embedded ServerSync
